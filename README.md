# 一院知时

## 简介
沿二十四节气尺为时间轴，通过农家小院在各个节气中的物候差异来展现节气由来的零依赖前段三维交互作品。采用Three.js框架。

## 核心特性

- **四时微缩农家小院**：覆盖**雨水、芒种、寒露、小雪**四个代表节气场景，程序化构建三开间粉墙黛瓦农舍、稻田/旱地、杏花/夏木/丹枫/雪枝、灯笼与火塘、动态雨雪/蜻蜓/落花落叶以及像素农夫农事动画。
- **情境化农事与时令微交互**：支持点击探索田间农候、案上四时节令饮食（青团、粽子、柿子、糍粑），并在寒露开启「下田开镰」成片收割稻穗留茬、在小雪开启「围炉煨糍」炭火烤糍粑。
- **传统色彩与实时冷暖光影**：基于中国传统五色体系与节气物候构建四时色彩方案，支持冷暖光影分离、双通道日影图与动态农事阴影实时更新，并提供 Canvas 2D 兼容回退。
- **电影感开场与丝滑阻尼视角**：内置多轴错拍摇臂开场运镜、六轴临界阻尼弹簧 + 拖拽惯性 + 对数空间平滑缩放 + 节气星盘缓动转场；支持鼠标、触控与键盘全功能操控，完整适配 `prefers-reduced-motion`。
- **立杆测影与节气小志**：按北纬 30.4°（江汉平原）实时计算正午太阳仰角、直射纬度与圭表影长，支持面板内一键对比四时日影；节气小志展示太阳黄经、古典诗句、七十二候、传统色谱与日影示意。
- **四季动态声景系统**：融合国风背景音乐、四时程序化环境音（春雨、夏风远禽、秋夜微虫、冬日围炉炭火）与农事交互音效，支持总音量、配乐与环境音独立混音调节。

## 静态部署

本项目面向 **Cloudflare Pages**（`https://yi-yuan-zhi-shi.pages.dev`）直接以仓库根目录 `/` 静态发布，无需构建命令；同时提供单文件离线预览版 `yard-preview.html`。

## 版本与协作

- 日常变更记录在 Git 提交里。阶段性交付用带说明的 Git Tag 标记，例如 `v1.0`。版本快照可在仓库的 Tags 页面查看，GitHub Releases 保持空置。
- `main` 用于维护可部署版本。协作者从 `main` 建短分支，推送分支后开 Pull Request，说明改动和验证方式。涉及画面或交互时，可附截图或 Cloudflare Pages 预览链接供合并前检查。
- 合并后如果需要撤回改动，用 `git revert` 保留撤回记录。已共享的 `main` 历史和版本标签避免强制覆盖。
