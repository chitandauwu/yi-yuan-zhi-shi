# 一院知时

## 简介
沿二十四节气尺为时间轴，通过农家小院在各个节气中的物候差异来展现节气由来的零依赖前段三维交互作品。采用Three.js框架。

## 核心特性

- **四时微缩农家小院**：覆盖**雨水、芒种、寒露、小雪**四个代表节气场景，程序化构建三开间粉墙黛瓦农舍、稻田/旱地、杏花/夏木/丹枫/雪枝、灯笼与暖炉、动态雨雪/蜻蜓/落花落叶以及像素农夫农事动画。
- **传统色彩与冷暖光影**：基于中国传统五色体系与节气物候构建四时色彩方案，WebGL 2 / WebGL 1 渲染器与 Canvas 2D 软件光栅化回退同步支持冷暖光影分离与双通道日影图。
- **丝滑阻尼视角操控**：六轴临界阻尼弹簧 + 拖拽速度追踪惯性 + 对数空间平滑缩放 + 最短路径复位；支持鼠标左键旋转、右键/中键平移、滚轮/双指缩放、键盘方向键与 `+`/`-`/`Home` 操控，完整适配 `prefers-reduced-motion`。
- **立杆测影与节气小志**：按北纬 30.4°（江汉平原）实时计算正午太阳高度角与圭表影长，点击田头立杆或工具栏按钮可平滑拉近观测；节气小志展示太阳黄经、古典诗句、七十二候（三候）、节气传统色及正午日影图示。

## 静态部署

本项目面向 **Cloudflare Pages**（`https://yi-yuan-zhi-shi.pages.dev`）直接以仓库根目录 `/` 静态发布，无需构建命令。

## 版本与协作

- 日常变更记录在 Git 提交里。阶段性交付用带说明的 Git Tag 标记，例如 `v0.6`。版本快照可在仓库的 Tags 页面查看，GitHub Releases 保持空置。
- `main` 用于维护可部署版本。协作者从 `main` 建短分支，推送分支后开 Pull Request，说明改动和验证方式。涉及画面或交互时，可附截图或 Cloudflare Pages 预览链接供合并前检查。
- 合并后如果需要撤回改动，用 `git revert` 保留撤回记录。已共享的 `main` 历史和版本标签避免强制覆盖。
